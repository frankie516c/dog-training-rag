# 다른 훈련사 채널 확장 시 키워드 매칭 품질 비교 (2026-08-25)

`reports/youtube_review_expansion_0825.md`가 발견한 문제 — 보듬TV CANDIDATE
분류가 거의 전부 **재생목록 소속**(`playlist:퍼피교육`)에서 나오고 실제 제목
신호는 약함(신규 69건 중 68건이 how-to 점수 0) — 를 확인한 뒤, "다른 채널을
긁으면 나아지는가"를 실측했다.

## 방법

`docs/SOURCES.md`가 이미 후보로 적어 둔 **설채현(수의사, 채널 "설채현의 놀로와",
`@knollo_with_dvmseol`)** 채널을 골라, 기존 `scripts/collect_youtube_metadata.py`
를 그대로(`YOUTUBE_CHANNEL_HANDLE` 환경변수만 바꿔) 실행했다. 코드 수정 없음.
출력은 `data/scratch/knollo_metadata.csv`(기존 보듬TV 파일과 분리, gitignore
대상)로 따로 받아 보듬TV 파일을 건드리지 않았다.

## 결과 — 두 채널 모두 600건 이상 규모에서 비교

| | 보듬TV (900건 수집) | 설채현 (600건 수집) |
|---|---:|---:|
| CANDIDATE 비율 | 81/900 (9.0%) | 60/600 (10.0%) |
| CANDIDATE 판정에 `playlist:` 근거 포함 | **거의 전부**(재생목록 소속이 핵심 근거) | **1/60 (1.7%)** |
| CANDIDATE 판정에 `title:` 근거 포함 | 소수 | **20/60 (33%)** |
| 신규 후보 중 how-to 채점(0~3점) **0점 아님** | 1/69 (1.4%) | **22/60 (36.7%)** |

CANDIDATE로 잡히는 **비율**(9~10%) 자체는 두 채널이 비슷하다. 차이는 **분류
근거의 질**이다 — 보듬TV는 "이 영상이 어느 재생목록에 들어있는가"가 CANDIDATE
여부를 사실상 결정하는데, 설채현 채널은 "제목에 실제 문제-해결 어구가
있는가"가 결정한다. 같은 자동 채점 기준을 그대로 적용했을 때 **0점이 아닌
비율이 1.4%→36.7%로 약 27배** 뛰었다.

### 설채현 채널에서 스코어 2점 받은 예시

- "산책할 때 마킹 하면 안 된다고? 마킹에 대한 오해와 방광염의 진실"
- (제목에 오해 지적 + 해결/설명 구조가 명시적으로 드러남)

## 왜 이런 차이가 나는가 — 추정

보듬TV는 예능·리액션 콘텐츠(강형욱과 게스트의 만남·소개)가 채널의 큰 축이라
"재생목록"이 콘텐츠 성격보다 세그먼트(퍼피교육/주니어교육 등 시리즈) 구분에
더 가깝고, 제목은 시청 유도형 문구(리액션·감정 자극)가 많다. 설채현 채널은
"논문 기반 팩트체크"·"행동학" 컨셉이 채널 정체성이라 제목 자체가 이미
"오해와 진실"·"해결책" 같은 설명형 문구를 쓰는 경향이 있다 — **채널의
편집 방향(예능형 vs 정보형)이 자동 분류 신호의 질을 좌우한다**는 뜻이다
[해석, 두 채널만으로 일반화하기엔 표본이 작음].

## 후속 확인 — 수동 자막 보유 여부 (결론: 0건, 채널 전체 배제 대상)

자동분류 품질은 좋았지만, `docs/SOURCES.md`의 자동자막 배제 원칙(벡터RAG
전환 이후에도 그대로 유효 — 자동자막을 쓰면 ASR 오류가 그대로 코퍼스에
섞인다는 게 이유였지, GraphRAG와는 무관한 정책)에 따라 실제 사용 가능 여부는
자막 종류로 결정된다. `yt-dlp -j --skip-download`로 각 영상의 `subtitles`
(수동)와 `automatic_captions`(자동) 딕셔너리를 직접 대조했다(다운로드 없이
메타데이터만 조회, 기존 보듬TV 조사와 동일한 방법).

| 표본 | 확인 건수 | 수동 한국어 자막 보유 |
|---|---:|---:|
| CANDIDATE 전체 60건 | 60 | **0건 (0%)** |
| CANDIDATE 아닌 영상 무작위 4건(교차검증용) | 4 | 0건 (0%, 그중 1건은 `live_chat`만 있음) |
| **합계** | **64** | **0건** |

`subtitles` 키가 완전히 빈 배열(`[]`)이고 언어 코드 표기 차이 때문이 아님을
직접 확인했다(`automatic_captions`는 `ab`(Abkhazian)부터 시작하는 표준
YouTube 자동번역 전체 언어 목록이 정상적으로 잡힘 — 조회 방법 자체는 정상
작동). **설채현 채널은 표본상 자막을 아예 수동으로 올리지 않는 채널로
보인다.**

## 최종 판단 — 이 채널은 (현재 정책 기준) 배제 대상

**제목/구조 기반 자동분류 품질은 보듬TV보다 27배 좋았지만, 자막이 전부
자동생성이라 이 프로젝트의 자동자막 배제 원칙에 걸려 그대로는 쓸 수 없다.**
"채널을 바꾸면 분류 품질이 오른다"는 가설은 맞았지만, 분류 품질과 실사용
가능성은 별개의 관문이었다 — 이번 채널은 첫 번째 관문(분류 품질)은 통과했지만
두 번째 관문(자막 종류)에서 걸렸다.

## 이번에 하지 않은 것

- `bodeum_youtube_manual_reviews.csv`(git 추적 원장)에 설채현 채널 영상을
  추가하지 않았다 — 자막 전량 자동생성이라 추가할 근거가 없다.
- `.env`의 `YOUTUBE_CHANNEL_HANDLE`을 영구적으로 바꾸지 않았다(일회성 환경변수
  오버라이드만 사용) — 보듬TV가 여전히 기본 채널이다.
- 자동자막을 ASR로 대체 사용하는 방안(자동자막 + 사람 검수)은 검토하지
  않았다 — 정책을 바꾸는 결정이라 범위 밖.
