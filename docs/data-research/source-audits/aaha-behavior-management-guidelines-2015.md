# Source audit: 2015 AAHA Canine and Feline Behavior Management Guidelines

> 이 문서는 사람이 검토하는 조사 기록이다. 괄호의 영문 이름은 Data Contract v0와 대조하기 위한 임시 표지이며 스키마나 직렬화 키가 아니다. 모든 판단은 provisional이며 후속 법률·의미 검토가 필요하다.

## 조사 상태 (`audit_status`)

`sampled` — AAHA 공식 가이드라인 목록과 행동 관리 섹션의 대표 HTML 페이지를 확인했다. 현재 웹 게시 상태와 2015년 내용 기준을 분리해 기록한다.

## 확인한 범위 (`scope_observed`)

가이드라인 목록과 `Core competency`, 불안·고통 신호, 개의 행동 발달, 우려 행동 평가, 행동 변화, 공포 최소화, 불안 환자 핸들링, 요약 메시지의 공식 HTML 표본을 확인했다. 의학·행동학 내용의 기준 연도는 2015년이다. 공식 랜딩 페이지의 웹 게시일은 2019-05-07이고 `Core competency` 페이지는 2019-05-10이다. 모든 부속 페이지를 전수 검토하지 않았다.

## 접근 방식 (`access_method`)

AAHA 공개 HTML을 브라우저로 수동 열람했다. PDF·인쇄본이나 원문 파일은 내려받지 않았다.

## 수집·접근 제약 (`collection_constraints`)

공개 웹 열람 가능. AAHA 이용약관은 사이트 콘텐츠 권리를 AAHA에 두며 포괄적 공개 라이선스를 제공하지 않는다. 자동 수집 조건·rate limit은 이번 조사에서 미확인이다.

## 라이선스 기록 (`license_record`)

공식 이용약관 https://www.aaha.org/about-aaha/terms-of-use/ 에서 일반적인 Creative Commons 재사용 허가는 확인되지 않았다(2026-08-12).

- 접근: 공개 HTML 열람 가능.
- 자동 수집, 원문 저장, 변형·파생, RAG 원문 적재, 재현·재배포, 상업 이용: 별도 허가가 없으므로 보류.
- 저장 검토 가능 정보: 서지 메타데이터, 2015 내용 기준과 2019-05-07·2019-05-10 웹 게시일의 구분, URL, locator candidate, 자체 작성 최소 요약.

## 콘텐츠 품질 (`content_quality`)

동물병원 맥락의 권위 있는 가이드라인으로 행동 징후·예방·관리·전문 평가를 구조적으로 다룬다. 그러나 내용 기준은 2015년이고 웹 게시가 2019년이라는 사실이 최신 임상 내용임을 뜻하지 않는다.

## 예상 용도 (`intended_role`)

수의학적 행동 관리, 공포·불안 신호 관찰, 예방과 적절한 의뢰에 대한 `clinical_context` 후보이다.

### 독립 주장 후보 (`provisional evidence relevance`)

- 2015 AAHA 가이드라인은 행동 평가와 관리가 일상적인 수의 진료의 일부라고 설명한다.
- 공포·불안·고통 신호를 조기에 식별하고 불필요한 공포를 줄이는 환경·핸들링을 고려해야 한다.

## 위험과 미확인 사항 (`risks_and_unknowns`)

2015년 이후 이를 대체하거나 갱신한 AAHA 가이드라인 존재 여부는 `needs_review`이다. 2019 웹 게시일을 의학적 내용의 연도로 오인하면 안 된다. 고양이 내용이 섞이며 개별 진단·약물·행동 처방은 수의사 판단이 필요하다. 세부 상담 문구는 `needs semantic review`이다.

## 조사 결론 (`recommendation`)

provisional recommendation: `proceed_with_conditions`

### provisional reuse assessment

공개 열람과 서지·locator 기록은 가능하지만 명시적 공개 라이선스가 없어 원문·표·도해 저장과 재현은 보류한다.

### provisional evidence relevance

의료·행동 안전 맥락에는 직접 관련된다. 다만 2015년 기준 자료이므로 현재 임상 권고로 사용할 때 최신성 검토가 필요하다.

### 허용 가능한 claim scope

2015 가이드라인이 제시하는 일반적 행동 평가·공포 최소화 원칙과 2019 웹 게시 사실만 허용한다. 최신 지침이라는 표현, 진단, 약물·사례별 처방은 허용하지 않는다.
