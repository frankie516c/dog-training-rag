# 소스 지도

조사 기준일 2026-08-11. 링크가 죽었으면 이 문서를 먼저 갱신할 것.

## 왜 2층 구조인가

한 채널만 긁으면 **검증할 수 없는 데이터**가 됩니다. 훈련사마다 처방이 갈리는 주제(예: 짖음 교정에 처벌을 쓸 것인가)에서 근거 없이 한쪽 말만 담게 되기 때문입니다.
반대로 공공 자료만으로는 실제 보호자가 던지는 질문("산책할 때만 리드줄을 물어뜯어요")에 대응이 안 됩니다.

- **1층**에서 사례와 발화를 가져오고
- **2층**에서 그게 표준 지침과 어긋나지 않는지 검증합니다.

## 1층 — 사례·발화 (유튜브)

| 소스 | 규모 | 메모 |
|---|---|---|
| 강형욱의 보듬TV `UCee1MvXr6E8qC_d2WEYTU5g` | 832개 / 84.4시간 | 실측 완료. 수동자막 약 25%. 2024년 논란 이후 삭제·비공개된 영상이 있는지 재수집 시 확인 필요 |
| KBS 「개는 훌륭하다」 공식 클립 | 2019.12 ~ 2024 | **정식 자막 비율이 높음.** 문제견 → 진단 → 처방 구조라 QA 형태로 가공하기 좋음. 인덱스 미수집 |
| 기타 훈련사·수의사 채널 | 미조사 | 설채현(놀아주는수의사), 이웅종 등. 한 사람 관점에 쏠리지 않게 하는 용도 |

수집은 `yt-dlp`. 자막만 받을 때는 `ffmpeg`가 필요 없습니다.

```powershell
yt-dlp --skip-download --write-subs --sub-langs "ko" --sub-format "vtt/best" `
       --write-info-json -o "data/subs/%(id)s.%(ext)s" <URL>
```

`--write-auto-subs`는 **의도적으로 빼두었습니다.** 자동자막을 받아두면 나중에 섞여 들어갑니다. 사유는 README의 "핵심 제약" 절 참고.

## 2층 — 정답 기준 (라이선스 명확)

### AI-Hub (회원가입 후 무료, 상업적 이용 조건부 허용)
- [반려동물 구분을 위한 동물 영상](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=59) — 514시간 개·고양이 행동 영상, bbox + 15개 관절 키포인트 각 750만 장. 국내 최대 규모. **행동 인식 모델로 확장할 경우의 주력 소스**
- [반려견·반려묘 건강정보 데이터](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=71520) — 건강정보 12만 건 + 메타데이터 4천 건
- 반려동물 안구질환 `562`, 질병진단 영상 근골격계 `501` / 복부 `498` / 흉부 `499` — 훈련이 아닌 의료 데이터지만, "이 행동은 통증이 원인일 수 있다"는 판단의 근거가 됨

### 정부·공공
- [동물사랑배움터](https://apms.epis.or.kr/) — 농식품부 공식 반려동물 온라인 교육. 사회화 교육·공공예절 커리큘럼
- **반려동물행동지도사** — 동물보호법상 국가자격 (2025년 1회 시행). 출제범위와 표준교재가 **사실상 국가가 정한 정답지**. 데이터 품질 검증 기준으로 쓸 것
- [농림축산식품 공공데이터포털](https://data.mafra.go.kr/), [동물등록 현황 API](https://www.data.go.kr/data/15103156/openapi.do) — 품종·연령 분포 보정용

### 영문 기관 자료 (인용 가능)
- **AVSAB 포지션 스테이트먼트** — 처벌 기반 훈련에 대한 학회 공식 입장. 훈련법 논쟁에서 근거 있는 답을 하려면 필수
- AKC, ASPCA, RSPCA
- 학술: Journal of Veterinary Behavior, Applied Animal Behaviour Science (PubMed / Semantic Scholar API)

### 커뮤니티 (품질 편차 큼, 필터링 전제)
- 네이버 지식iN 강아지 훈련 카테고리 — 질문-답변 구조가 그대로 쓸 만하나 **채택 답변 + 답변자 등급**으로 걸러야 함
- Reddit `r/Dogtraining`, `r/puppy101`(위키가 잘 정제됨), `r/OpenDogTraining`
  - 주의: **Pushshift는 2023년부터 모더레이터 전용으로 막혔습니다.** 공식 API(PRAW)나 HuggingFace 아카이브 덤프를 쓸 것

## 라이선스·저작권 메모

이 저장소는 **개인 학습·포트폴리오용 비공개**를 전제로 합니다. 그 전제가 바뀌면 소스 구성을 다시 짜야 합니다.

문체부 생성형 AI 학습 관련 안내서 기준, 공정이용(저작권법 제35조의5) 판단에서 불리해지는 대표 케이스는 다음과 같습니다.

- 원저작물의 문장·구성·표현을 **실질적으로 동일·유사하게 재현**하는 결과물
- robots.txt·ToS로 수집이 금지된 자료, 로그인·유료 구간 자료의 무단 수집

즉 **한 사람의 채널만 통째로 떠서 그 말투와 처방을 그대로 재현하는 모델**이 가장 불리한 자리에 섭니다. YouTube ToS도 자막·영상 스크래핑을 명시적으로 금지합니다.

따라서 공개·서비스화로 방향이 바뀔 경우:

1. 2층(공공·기관) 비중을 올리고 1층 의존을 낮출 것
2. 여러 훈련사 소스를 섞어 특정 개인 복제가 되지 않게 할 것
3. 원문 그대로의 장문 재현을 차단하는 조치를 넣을 것
4. 수집물은 어떤 경우에도 저장소에 커밋하지 말 것 (현재 `data/` gitignore)
