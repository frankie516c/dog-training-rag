# STATUS — 메인 화면 픽셀 룸 실험

## 지금 상태

- 최신 초안은 `drafts/v7-growing-pixel-room.html`이다.
- 방은 문·창문·벽·바닥·울타리만 있는 빈 상태에서 시작하고, 서비스 과제를 완료할 때마다 소품이 하나씩 해금된다.
- 현재 소품은 크림 러그, 화분, 강아지 집, 공, 수납장, 장난감 바구니, 밥·물그릇, 교체용 세이지 러그까지 8종이다.
- 모든 소품은 독립 투명 PNG이며 드래그 이동, 보관함 넣기, 같은 카테고리 교체, `localStorage` 저장이 동작한다.
- 소품은 방 바닥의 원근 다각형 밖으로 나갈 수 없고, 바닥 접점 Y 좌표에 따라 소품과 강아지의 앞뒤 레이어가 자동으로 정해진다.
- 강아지는 네 장의 보행 프레임을 순환하면서 여러 지점 사이를 스스로 걷는다. 클릭하면 걷기를 멈추고 반응한다.

## 사용한 기술

- HTML/CSS/순수 JavaScript로 만든 프레임워크 없는 독립 목업
- CSS 커스텀 속성과 `image-rendering: pixelated`를 이용한 반응형 픽셀 합성
- Pointer Events 기반 드래그, 바닥 접점 앵커, 원근 다각형 좌표 제한
- 바닥 깊이 기반 동적 `z-index`
- PNG 프레임 교체와 CSS 스텝 애니메이션을 결합한 강아지 보행
- `localStorage` 기반 진행도와 배치 좌표 저장
- `prefers-reduced-motion` 접근성 처리
