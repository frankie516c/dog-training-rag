# HISTORY — 메인 화면 캐릭터 디자인 실험

날짜는 모두 2026-08-24 세션 기준.

## 1. 시작 — 요청

`dog-training-rag-retrieval`의 메인 화면을 귀여운 캐릭터 중심으로 개발하기로 하고, 3가지 실험 방향을 잡음:

1. **도트(픽셀) 버전** — 강아지도 방도 픽셀 아트로
2. **포즈 스왑 일러스트** — SVG 파츠 조립이 아니라, 갸우뚱/꼬리흔들기 같은 정해진 동작을 통 일러스트로 미리 그려서 방 안에서 재생
3. **krea2 + 2D 리깅** — krea2로 이미지를 받아 견종 프리셋에 매칭한 뒤, 파츠별 2D 리깅으로 자연스러운 움직임 구현

레퍼런스로 준 댕스(DAENGS) 앱 캡처가 "기본틀 UI" — 헤더, AI 채팅바, 산책 요약 카드, 하단 내비 구조를 그대로 따르기로 함.

## 2. 진행 방식 결정

- 3개 실험을 순차가 아니라 **러프하게 동시 비교**
- 지금 단계는 **레포 코드 커밋 없이 Artifact(claude.ai 목업)로만 비교** — 방향이 정해지면 그때 실제 프론트엔드 스택을 정해서 레포에 세팅

## 3. v1 — 3개 실험 동시 비교 목업

`drafts/v1-three-experiments.html`

기본틀 레이아웃(로고/아이콘, 채팅바, 통계 카드, 하단 내비)은 고정하고 "방 안의 강아지" 영역만 세 가지로 다르게 만든 폰 프레임 3개를 나란히 배치.

- 실험1: CSS 블록 방 + Canvas로 그린 픽셀 강아지 (좌표 규칙 기반 생성, 꼬리 흔들기·눈 깜빡임 애니메이션)
- 실험2: 통 SVG 일러스트 3장(대기/갸우뚱/꼬리흔들기)을 6초 주기로 opacity 전환
- 실험3: 머리·귀·꼬리·몸통을 각각 다른 주기로 흔들리게 해 "관절별 움직임" 개념만 보여주는 러프 버전 (krea2 실제 연동은 아직 없음)

## 4. 방향 압축 — v2

사용자 피드백: 실험 2는 제거하고 실험 1·3만 유지. 실험 1은 기본틀 UI만큼 소품 밀도를 올리고, 강아지 크기를 비율은 유지한 채 축소.

`drafts/v2-dot-and-rig.html`

- 실험 2(포즈 스왑) SVG·CSS·keyframes 전부 제거
- 실험 1에 문·환영매트·액자·선반+공·화분 추가 (기본틀 UI의 소품 밀도에 맞춤)
- 픽셀 강아지 캔버스 셀 크기 9px→7px로 축소 (그리드 좌표 로직은 그대로라 비율 동일, 크기만 작아짐)

## 5. krea2 로컬 실행 가능성 조사

실험 3을 실제로 구현하려면 krea2 연동이 필요해서, 이 PC(작업 데스크톱)에 모델을 직접 깔 수 있는지 확인.

**PC 사양**: i7-8700 (6C/12T) / RAM 16GB(슬롯 4개 중 2개 사용, 여유 2개) / RTX 3050 VRAM 6GB / C: 139GB 여유 / 네트워크 정상

**krea2 실체 확인** (공식 문서 + HuggingFace):
- `krea/Krea-2-Raw`, `krea/Krea-2-Turbo` — **13B 파라미터** text-to-image 모델
- 배포 형태: 호스팅 API가 기본, 셀프호스트는 옵션 (오픈 웨이트 + GGUF 양자화 공개)
- GGUF 크기: Q2_K 4.89GB ~ Q8_0 13.7GB

**판단**: VRAM 6GB가 병목. Q2_K는 가중치만 겨우 들어가지만 텍스트 인코더·VAE·활성화 메모리까지 얹으면 빠듯해서 품질 저하·속도 저하가 크다 → **로컬 셀프호스팅 비추천, 호스팅 API 연동 권장**. "동일 사양 새 PC"로 바꿔도 결론 동일 (VRAM은 물리적으로 고정, RAM 여유만 조금 늘 수 있음). 프리셋 매칭·2D 리깅용 보조 모델은 훨씬 가벼워 이 GPU로 충분.
